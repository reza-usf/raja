# بات تلگرام پایش ظرفیت بلیت قطار رجا

این پروژه یک **هشداردهنده ظرفیت** است؛ خرید خودکار، رزرو صندلی، ورود به حساب، حل کپچا یا پرداخت انجام نمی‌دهد.

## امکانات

- ثبت مبدا و مقصد
- بازه تاریخ شمسی (مثلاً `1405/06/08` تا `1405/06/20`)
- تعداد مسافر ۱ تا ۶
- نوع مسافر: مسافرین عادی، ویژه برادران، ویژه خواهران
- ذخیره پایش‌ها در SQLite
- بررسی دوره‌ای با حداقل فاصله ۶۰ ثانیه
- جلوگیری از هشدار تکراری برای همان وضعیت
- هشدار دوباره اگر ظرفیت ناپدید شود و بعد دوباره برگردد
- ذخیره screenshot و HTML در `data/debug/` اگر ظاهر سایت رجا تغییر کند

## نکته مهم درباره رجا

برای این کاربرد، API عمومی و مستند رسمی پیدا نشده است. بنابراین بات با Playwright همان فرم عمومی سایت
`https://www.raja.ir/` را مانند مرورگر پر می‌کند.

ظاهر سایت ممکن است عوض شود. به همین دلیل `app/raja.py` چند selector جایگزین دارد و در صورت خطا snapshot
می‌سازد. ابزار `tools/diagnose_raja.py` هم برای پیدا کردن selector جدید اضافه شده است.

## راه‌اندازی سریع با Docker

### 1) ساخت بات تلگرام

در تلگرام به `@BotFather` برو:

1. `/newbot`
2. نام و username بات را تعیین کن
3. Token را کپی کن

### 2) تنظیم فایل env

```bash
cp .env.example .env
```

داخل `.env`:

```env
TELEGRAM_BOT_TOKEN=توکن_بات
CHECK_INTERVAL_SECONDS=60
RAJA_HEADLESS=true
RAJA_BASE_URL=https://www.raja.ir/
DATABASE_PATH=data/bot.sqlite3
DEBUG_DIR=data/debug
```

### 3) اجرا

```bash
docker compose up -d --build
```

لاگ:

```bash
docker compose logs -f
```

توقف:

```bash
docker compose down
```

## اجرا بدون Docker

Python 3.11+:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
cp .env.example .env
python -m app.main
```

در ویندوز:

```powershell
.venv\Scripts\activate
```

## نمونه تهران → شیراز، ۸ تا ۲۰ شهریور

در بات:

1. «پایش جدید»
2. مبدا: `تهران`
3. مقصد: `شیراز`
4. شروع: `1405/06/08` یا `8 شهریور 1405`
5. پایان: `1405/06/20` یا `20 شهریور 1405`
6. تعداد مسافر
7. نوع مسافر

اگر سال را در عبارت متنی ننویسی، سال شمسی جاری در نظر گرفته می‌شود.

## درباره فاصله یک دقیقه

اگر بازه ۱۳ روزه باشد، هر دور پایش می‌تواند تا ۱۳ جست‌وجوی سایت ایجاد کند. پروژه درخواست‌ها را ترتیبی
می‌فرستد و بین تاریخ‌ها کمی مکث می‌کند. حداقل فاصله در کد ۶۰ ثانیه است.

## اگر رجا تغییر کرد و بات خطا داد

اگر سه بار پشت‌سرهم خطا شود، بات یک هشدار می‌دهد و همچنان تلاش می‌کند.

فایل‌های زیر را بررسی کن:

```text
data/debug/raja-error-YYYYMMDD-HHMMSS.png
data/debug/raja-error-YYYYMMDD-HHMMSS.html
```

برای تشخیص تعاملی:

```bash
RAJA_HEADLESS=false python tools/diagnose_raja.py
```

این ابزار inputها و buttonهای قابل مشاهده را چاپ می‌کند و screenshot می‌گیرد. بعد selectorهای
`app/raja.py` را بر اساس DOM جدید اصلاح کن.

## اجرا روی VPS

برای پایش ۲۴/۷ یک VPS لینوکسی مناسب است. پروژه را کپی کن، Docker را نصب کن و:

```bash
docker compose up -d --build
```

بهتر است سرور از شبکه‌ای باشد که سایت رجا را بدون مشکل باز می‌کند؛ بعضی IPهای دیتاسنتری ممکن است
با محدودیت CDN یا جغرافیایی مواجه شوند.

## امنیت

- Token بات را داخل Git commit نکن.
- فایل `.env` را خصوصی نگه دار.
- پروژه هیچ اطلاعات بانکی یا رمز حساب رجا را ذخیره نمی‌کند.
